## VS Code 是什么
**是一个高度可定制的代码编辑器。** 可以想象是类似于电脑端的文本编辑器，可以编辑各种格式的内容。只不过这个编辑器相比文本编辑器来说支持非常多的扩展。   

**特点是**：轻量级，Mac Win都支持，内置Git支持，内置终端，能看到文件夹结构，支持多种编程语言。


你可以把它当作一个单纯的文本编辑器用，也可以通过追加很多拓展，让它变成一个你想要的强大的工具。   

> VS Code官网: [Visual Studio Code](https://code.visualstudio.com/)

## 为什么选择 VS Code
本人是经济学研究生。
> 也就是“吃着理科的苦，落着文科的名”的一种专业。   

经济学研究经常使用多种操作语言，比如数理统计中常用的软件，STATA，R，或者Python，以及擅长矩阵计算的MatLab。同时身为博士生，可能还需要维护自己和课题组的网站，所以也需要HTML和CSS等代码。   

另一方面，又不会像开发一个软件一样，有大量的代码需要维护，至少我是这样的。因此，**经常会需要用不同的计算机语言进行一些简短代码的运行。**   

所以选择 VS code 就相当于选择了一个能打开以及运行几乎所有语言的一个编辑器。   

当然JupyterLab 或者 Jupyter Notebook 也可以编辑多种语言。甚至不需要本地部署，可以直接在线编辑。点击[Try Jupyter](https://jupyter.org/try)尝试JuptyerLab或者Jupyter Notebook。
但是本人有离线书写Markdown文件的需求，再加上需要用Git管理网站，所以选择了VS Code。   

**基于以下几点，本人强烈推荐经济学博士生使用VS Code：**
- Win和Mac都可用，方便更换电脑系统
- 免费！
- 亲测Mac启动飞快，无需长时间加载
- 可以用来编写个人学术主页的HTML文件和CSS文件，直接链接Github，方便拉取和推送`Pull`&`Push`
- 可以支持Jupyter Notebook文件，也就是扩展名为`.ipynb`的文件
- 可以直接写Markdown文件，同时可预览。非常方便


## VScode不能包治百病！
根据本人使用体会，VS Code无法替代专业的数据分析软件，比如：
- 无法替代STATA
- 无法替代Matlab
- 无法替代RStudio
  
> 说了半天最主要的数据分析软件都替代不了。
